==========================================
   ⚠️ 重要说明
==========================================

为什么要修改 .env.development 而不是 .env.production？

因为：
- npm run dev（开发模式）读取 .env.development
- npm run build（生产构建）读取 .env.production

你现在用的是 npm run dev，所以要改 .env.development！
