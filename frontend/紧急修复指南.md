# 🚨 紧急修复指南 - 头像不显示 & 退出不了

## 问题1：头像还是不显示

### 原因
你修改了 `.env.production` 文件，但**环境变量的修改需要重启前端服务才能生效**！

### 解决方案

#### 第一步：停止当前前端服务
在运行前端的终端/CMD窗口中，按 `Ctrl + C` 停止服务。

#### 第二步：重新启动前端服务
```bash
npm run dev
```

#### 第三步：清除浏览器缓存
1. 在浏览器中按 `Ctrl + Shift + Delete`
2. 选择"缓存的图片和文件"
3. 点击"清除数据"

或者直接按 `Ctrl + F5` 强制刷新页面。

## 问题2：教师退出不了

### 可能的原因

#### 原因1：没有点击确定按钮
退出登录会弹出确认对话框，需要点击"确定"按钮才会退出。

#### 原因2：浏览器控制台有错误
1. 按 `F12` 打开浏览器开发者工具
2. 查看 Console 标签，看是否有红色错误信息
3. 如果有错误，请截图发给我

#### 原因3：路由问题
如果点击退出后没有跳转到登录页：
1. 检查浏览器地址栏，看URL是否变成了 `/login`
2. 如果是，但页面没有显示登录界面，可能是路由配置问题

### 测试退出功能
1. 登录教师账号
2. 点击右上角的头像/用户名
3. 在下拉菜单中点击"退出登录"（或"退出"图标）
4. 在弹出的确认对话框中点击"确定"
5. 应该会跳转到登录页面

## 完整的部署流程

### 服务器端（你的电脑）

1. **修改 `.env.production`**
   ```bash
   VITE_API_BASE_URL=http://192.168.219.134:8080
   ```

2. **启动后端服务**
   ```bash
   # 在 backend 目录下
   mvn spring-boot:run
   ```

3. **启动前端服务**
   ```bash
   # 在 frontend 目录下
   npm run dev
   ```

4. **配置防火墙**
   ```powershell
   # 管理员CMD
   netsh advfirewall firewall add rule name="OnlineExam" dir=in action=allow protocol=TCP localport=5173,8080
   ```

### 客户端（其他电脑）

1. **确保连接同一WiFi**

2. **访问地址**
   ```
   http://192.168.219.134:5173
   ```

3. **清除浏览器缓存** 
   按 `Ctrl + Shift + Delete`，清除"缓存的图片和文件"

## 常见错误排查

### 错误1：图片请求 404
**症状：** Network 标签显示图片请求返回 404

**解决：**
1. 检查后端是否正常运行
2. 检查图片文件是否真的存在于 `backend/uploads/` 目录
3. 检查后端控制台是否有错误

### 错误2：CORS 错误
**症状：** Console 显示 "Access to ... has been blocked by CORS policy"

**解决：**
1. 确保后端的 `CorsConfig.java` 配置正确（已配置）
2. 重启后端服务

### 错误3：连接被拒绝
**症状：** Network 显示 "ERR_CONNECTION_REFUSED"

**解决：**
1. 检查后端是否在运行
2. 检查防火墙是否开放了 8080 端口
3. 检查 IP 地址是否正确
