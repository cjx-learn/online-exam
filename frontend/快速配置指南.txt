=====================================================
   在线考试系统 - 快速配置指南（局域网访问）
=====================================================

【问题】在其他电脑上无法看到头像和图片

【原因】代码中硬编码了 localhost，在其他电脑上 localhost 指向访问者自己的电脑

【解决方案】

第一步：查看你的服务器 IP 地址
--------------------------------
Windows 用户：
1. 按 Win+R，输入 cmd，回车
2. 输入命令：ipconfig
3. 找到 "IPv4 地址"，例如：192.168.1.100

第二步：修改配置文件
--------------------------------
打开文件：.env.production

将这一行：
VITE_API_BASE_URL=http://192.168.1.100:8080

改为你的实际 IP：
VITE_API_BASE_URL=http://你的IP地址:8080

例如：
VITE_API_BASE_URL=http://192.168.1.100:8080

第三步：重新启动项目
--------------------------------
1. 停止当前的前端服务（按 Ctrl+C）
2. 重新启动：npm run dev

第四步：在其他电脑上访问
--------------------------------
1. 确保其他电脑和服务器在同一个局域网（连接同一个 WiFi）
2. 在其他电脑的浏览器中输入：
   http://你的IP地址:5173

例如：
http://192.168.1.100:5173

第五步：防火墙配置（如果访问不了）
--------------------------------
Windows 用户：
1. 打开"控制面板" -> "Windows Defender 防火墙"
2. 点击"高级设置"
3. 点击"入站规则" -> "新建规则"
4. 选择"端口" -> 下一步
5. 选择"TCP"，输入端口"5173,8080" -> 下一步
6. 选择"允许连接" -> 下一步
7. 全部勾选 -> 下一步
8. 输入名称"OnlineExam" -> 完成

或者使用命令（管理员权限打开 CMD）：
netsh advfirewall firewall add rule name="OnlineExam" dir=in action=allow protocol=TCP localport=5173,8080

【测试】
1. 登录教师账号
2. 点击头像 -> 修改信息 -> 上传新头像
3. 查看头像是否正常显示

【常见问题】

Q: 还是看不到头像？
A: 1. 检查 .env.production 文件中的 IP 是否正确
   2. 检查防火墙是否开放了 8080 端口
   3. 打开浏览器 F12，看 Network 标签，图片请求的 URL 是什么

Q: 提示"无法连接"？
A: 1. 确保两台电脑在同一个局域网
   2. 确保后端服务正在运行
   3. 检查防火墙设置

Q: 提示 CORS 错误？
A: 后端已经配置好了 CORS，确保后端服务正常启动
