# 在线考试系统 - 局域网/跨设备访问配置指南

## 问题描述
在其他电脑上无法访问头像和图片，因为代码中硬编码了 `localhost:8080`。

## 解决方案

### 1. 修改环境配置文件

#### `.env.production` 文件
将服务器 IP 地址改为你的实际 IP：

```bash
# 生产环境配置
# 请将下面的 IP 地址改为你的服务器实际 IP 地址
VITE_API_BASE_URL=http://192.168.1.100:8080
```

**如何获取服务器 IP 地址：**
- Windows: 打开 CMD，输入 `ipconfig`，查看 IPv4 地址
- Mac/Linux: 打开终端，输入 `ifconfig` 或 `ip addr`

例如：
- 局域网: `http://192.168.1.100:8080`
- 公网: `http://你的公网IP:8080`

### 2. 启动前端项目

**开发环境（localhost）：**
```bash
npm run dev
```

**生产环境（局域网访问）：**
```bash
npm run build
npm run preview
```

或者直接部署到服务器（如 Nginx）。

### 3. 后端配置

#### 确保后端允许局域网访问

修改 `application.yml` 或 `application.properties`：

```yaml
server:
  address: 0.0.0.0  # 允许所有IP访问
  port: 8080
```

#### CORS 配置已完成
后端的 `CorsConfig.java` 已经配置为允许所有来源跨域访问。

### 4. 防火墙配置

**确保端口开放：**
- 前端端口: 5173 (开发) 或 80/443 (生产)
- 后端端口: 8080

**Windows 防火墙：**
```powershell
# 开放后端端口
netsh advfirewall firewall add rule name="OnlineExam Backend" dir=in action=allow protocol=TCP localport=8080

# 开放前端端口（如果需要）
netsh advfirewall firewall add rule name="OnlineExam Frontend" dir=in action=allow protocol=TCP localport=5173
```

**Linux 防火墙：**
```bash
# ufw
sudo ufw allow 8080
sudo ufw allow 5173

# firewalld
sudo firewall-cmd --add-port=8080/tcp --permanent
sudo firewall-cmd --add-port=5173/tcp --permanent
sudo firewall-cmd --reload
```

### 5. 访问地址

**开发环境：**
- 前端: `http://服务器IP:5173`
- 后端: `http://服务器IP:8080`

**生产环境：**
- 前端: `http://服务器IP` (如果部署在 80 端口)
- 后端: `http://服务器IP:8080`

## 常见问题

### Q: 仍然显示不出头像？
A: 
1. 检查 `.env.production` 中的 IP 是否正确
2. 检查防火墙是否开放了 8080 端口
3. 打开浏览器开发者工具（F12），查看 Network 标签，看图片请求的URL是否正确

### Q: 提示 CORS 错误？
A: 后端 CorsConfig 已配置，确保后端服务正常启动

### Q: 无法访问 5173 端口？
A: 
1. 确保 Vite 配置中 `host: '0.0.0.0'`
2. 检查防火墙是否开放了 5173 端口
