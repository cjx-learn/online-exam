==========================================
   🚨 头像不显示 & 退出不了 - 修复步骤
==========================================

问题：你修改了 .env.production，但前端服务还在使用旧的配置！

【关键】修改环境变量后，必须重启前端服务！

==========================================
   第一步：重启前端服务
==========================================

1. 在运行前端的窗口中，按 Ctrl + C 停止服务
2. 重新输入命令：npm run dev
3. 等待服务启动完成

==========================================
   第二步：清除浏览器缓存
==========================================

方法1：强制刷新
按 Ctrl + F5

方法2：清除缓存
按 Ctrl + Shift + Delete
选择"缓存的图片和文件"
点击"清除数据"

==========================================
   第三步：测试
==========================================

1. 在其他电脑的浏览器中访问：
   http://192.168.219.134:5173

2. 登录教师账号

3. 测试头像：
   - 点击右上角头像
   - 点击"修改信息"
   - 上传新头像
   - 查看是否显示

4. 测试退出：
   - 点击右上角头像/用户名
   - 点击"退出登录"
   - 在弹出的对话框中点击"确定"
   - 应该跳转到登录页

==========================================
   如果还是不行
==========================================

1. 按 F12 打开浏览器开发者工具
2. 切换到 Network 标签
3. 刷新页面
4. 查看图片请求的URL是否正确：
   应该是：http://192.168.219.134:8080/api/uploads/...
   而不是：http://localhost:8080/api/uploads/...

5. 如果URL还是localhost，说明前端服务没有重启成功
   请完全关闭终端窗口，重新打开，再运行 npm run dev

==========================================
   关于退出登录
==========================================

退出登录需要两步：
1. 点击"退出登录"菜单项
2. 在弹出的确认对话框中点击"确定"按钮

如果点击后没反应：
- 查看浏览器控制台（F12 -> Console）是否有错误
- 确保没有点击"取消"按钮

==========================================
   防火墙配置（如果访问不了）
==========================================

管理员权限打开 CMD，运行：

netsh advfirewall firewall add rule name="OnlineExam" dir=in action=allow protocol=TCP localport=5173,8080

==========================================
   完整的启动流程
==========================================

1. 确保 .env.production 中的IP正确：
   VITE_API_BASE_URL=http://192.168.219.134:8080

2. 启动后端（在 backend 目录）：
   mvn spring-boot:run

3. 启动前端（在 frontend 目录）：
   npm run dev

4. 在其他电脑访问：
   http://192.168.219.134:5173

==========================================
   核心问题
==========================================

你已经做了：
✅ 修改了 .env.production 的 IP 地址

你还需要做：
❌ 重启前端服务（这是关键！）
❌ 清除浏览器缓存

修改 .env 文件后，不重启服务，前端还在使用旧配置！
