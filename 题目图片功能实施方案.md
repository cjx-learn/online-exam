# 题目图片功能实施方案

## 📌 功能需求
在题目中支持插入图片，用于数学公式、图表、图形等需要可视化展示的题目内容。

## 🎯 实施步骤

### 1. 数据库修改

#### 方案A：单图片字段（推荐用于简单场景）
```sql
ALTER TABLE question ADD COLUMN image VARCHAR(500) COMMENT '题目图片URL' AFTER content;
```

#### 方案B：多图片字段（推荐用于复杂场景）
```sql
ALTER TABLE question ADD COLUMN images TEXT COMMENT '题目图片URLs，JSON格式数组' AFTER content;
```
存储格式示例：`["uploads/questions/2025/12/07/abc123.jpg", "uploads/questions/2025/12/07/def456.jpg"]`

#### 2.3 文件上传控制器修改 `FileController.java`

添加题目图片上传接口：
```java
@PostMapping("/upload/question-image")
public Map<String, Object> uploadQuestionImage(@RequestParam("file") MultipartFile file) {
    Map<String, Object> result = new HashMap<>();
    try {
        if (file.isEmpty()) {
            result.put("code", 400);
            result.put("message", "文件为空");
            return result;
        }

        // 验证文件类型
        String contentType = file.getContentType();
        if (contentType == null || !contentType.startsWith("image/")) {
            result.put("code", 400);
            result.put("message", "只能上传图片文件");
            return result;
        }

        // 验证文件大小（5MB限制）
        if (file.getSize() > 5 * 1024 * 1024) {
            result.put("code", 400);
            result.put("message", "图片大小不能超过5MB");
            return result;
        }

        String relativePath = FileUtil.uploadFile(file, "questions");
        
        result.put("code", 200);
        result.put("message", "上传成功");
        result.put("data", relativePath);
        return result;
    } catch (Exception e) {
        e.printStackTrace();
        result.put("code", 500);
        result.put("message", "上传失败：" + e.getMessage());
        return result;
    }
}
```

### 3. 前端修改

#### 3.1 创建题目图片上传组件 `QuestionImageUpload.vue`

```vue
<template>
  <div class="question-image-upload">
    <div v-if="imageUrl" class="image-preview">
      <img :src="fullImageUrl" alt="题目图片" />
      <div class="image-actions">
        <el-button size="small" type="primary" @click="handleReupload">
          <el-icon><RefreshRight /></el-icon>
          重新上传
        </el-button>
        <el-button size="small" type="danger" @click="handleRemove">
          <el-icon><Delete /></el-icon>
          删除图片
        </el-button>
      </div>
    </div>
    
    <el-upload
      v-else
      class="image-uploader"
      :action="uploadUrl"
      :show-file-list="false"
      :on-success="handleSuccess"
      :on-error="handleError"
      :before-upload="beforeUpload"
      accept="image/*"
      :headers="{ Authorization: token }"
    >
      <div class="upload-placeholder">
        <el-icon class="upload-icon"><Plus /></el-icon>
        <div class="upload-text">点击上传题目图片</div>
        <div class="upload-hint">支持 JPG、PNG、GIF，最大 5MB</div>
      </div>
    </el-upload>
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'
import { ElMessage } from 'element-plus'
import { Plus, RefreshRight, Delete } from '@element-plus/icons-vue'

const props = defineProps({
  modelValue: {
    type: String,
    default: ''
  }
})

const emit = defineEmits(['update:modelValue'])

const uploadUrl = 'http://localhost:8080/api/file/upload/question-image'
const token = localStorage.getItem('token') || ''

const imageUrl = computed({
  get: () => props.modelValue,
  set: (val) => emit('update:modelValue', val)
})

const fullImageUrl = computed(() => {
  if (imageUrl.value && !imageUrl.value.startsWith('http')) {
    return 'http://localhost:8080/api' + imageUrl.value
  }
  return imageUrl.value
})

const beforeUpload = (file) => {
  const isImage = file.type.startsWith('image/')
  const isLt5M = file.size / 1024 / 1024 < 5

  if (!isImage) {
    ElMessage.error('只能上传图片文件！')
    return false
  }
  if (!isLt5M) {
    ElMessage.error('图片大小不能超过 5MB！')
    return false
  }
  return true
}

const handleSuccess = (response) => {
  if (response.code === 200) {
    imageUrl.value = response.data
    ElMessage.success('图片上传成功')
  } else {
    ElMessage.error(response.message || '上传失败')
  }
}

const handleError = () => {
  ElMessage.error('上传失败，请重试')
}

const handleReupload = () => {
  imageUrl.value = ''
}

const handleRemove = () => {
  imageUrl.value = ''
  ElMessage.success('图片已删除')
}
</script>
```

1. **图片预览**：在编辑时提供清晰的预览

## ⚠️ 注意事项

1. **存储空间**：规划好图片存储位置和清理策略
2. **访问权限**：确保图片URL可以正确访问
3. **CDN优化**：流量大时考虑使用CDN加速
4. **数据迁移**：如有旧数据，需要考虑迁移方案
5. **备份策略**：定期备份上传的图片文件
